# SDVX-ProModel
Convert your Sound Voltex panel into a controller

<img width="500" alt="image" src="https://github.com/user-attachments/assets/916eada5-cab2-47ef-b5a9-e3f7cc2dc88d" />

# Features
- Almost 1:1 to a real cabinet
- Side LED support
- Headphone Jack
- Adapter plate for [Yuancon](https://shop.yuancon.io/products/yuancon-sdvm-encoder-adjustable-high-precision-control-module?variant=51987689111869) style encoder/knobs


# Requirements
- SDVX Control panel from a Nemsys Cabinet
- Access to a Laser cutter that is at least 80x40cm big (or any laser cutting service)
- Access to a 3D Printer
- Some mounting hardware
- Electronics
- DIY Skills
